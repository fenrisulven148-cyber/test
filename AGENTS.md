# AGENTS.md — WorldSim

Консольная симуляция маленького города. .NET 8, C#.

## Структура

```
WorldSim.sln
src/
  WorldSim.Core/      # библиотека логики симуляции (без консоли и графики)
    GameConfig.cs     # ВСЕ настраиваемые числа симуляции
    Goods.cs          # enum GoodsType (еда/дерево/инструменты), Profession
    Resident.cs       # житель: голод, деньги, инвентарь
    Market.cs         # рынок: запасы, цены (спрос/предложение), касса
    World.cs          # ядро: тики, производство, торговля, смерть, отчёты
    DayReport.cs      # record суточной сводки
  WorldSim.Console/   # консольный раннер: печатает сводку каждый день
tests/
  WorldSim.Tests/     # xUnit-тесты обязательных свойств симуляции
```

## Правила запуска

```bash
dotnet build
dotnet test
dotnet run --project src/WorldSim.Console -- [totalTicks] [seed]   # по умолчанию 720 тиков, seed 1234
```

## Модель симуляции (коротко)

- 1 тик = 1 час; 24 тика = 1 день (`GameConfig.TicksPerDay`).
- 20 жителей: 8 фермеров (еда), 6 дровосеков (дерево), 4 кузнеца (инструменты из дерева), 2 торговца.
- Голод растёт каждый тик на `HungerPerTick`, ограничен `HungerMax` (100).
- Житель с голодом ≥ HungerMax на конец дня копит `StarvingDays`; если он больше
  `MaxStarvingDays` подряд — умирает.
- Еду жители покупают на рынке за свои деньги (через торговцев).
- Цена товара = `BasePrice * ((TargetStock+1)/(Stock+1))^PriceSensitivity`, жёстко
  ограничена `[MinPrice, MaxPrice]`.

## Порядок тика (World.TickOnce)

Для каждого живого жителя по фиксированному порядку:
1. `AdvanceHunger` — голод +HungerPerTick (не выше 100);
2. `Produce` — производство по профессии (кузнец тратит дерево из инвентаря);
3. `SellProduce` — излишки сдаются рынку за деньги из кассы рынка;
4. `TryBuyFood` — если голод ≥ 50 и есть деньги, покупает еду у рынка; деньги
   уходят в кассу рынка.
В конце тика: проверка смертей (раз в сутки) и пересчёт цен.

## Экономическое допущение про деньги (важно для теста)

Допущение: **эмиссия денег происходит только при создании мира** — банк выдаёт
стартовый капитал жителям (`StartingMoneyMin..Max`) и кассу рынка
(`MarketStartingCash`). Всё остальное — обмен товара ↔ деньги между агентами.
Деньги **сгорают** только при смерти жителя (его остаток изымается из обращения).
Инвариант, который проверяют тесты каждый тик:

```
деньги живых + касса рынка == EmittedTotal − BurnedTotal
```

## Допущения, выбранные «простым вариантом»

- Игрока нет — simulation полностью автономна.
- Спрос моделируется косвенно: покупки еды выводят товар с рынка → цена растёт;
  продажи фермеров наполняют рынок → цена падает. Отдельной функции спроса нет.
- Жители едят только на рынке за деньги (правило 6); собственный запас еды они
  продают, оставляя себе ~суточный объём (`KeepAmount`).
- Порог покупки еды — голод ≥ 50 (условие «проголодался»), константа в `World.TryBuyFood`.
- Кузнец крафтит инструменты только из собственного инвентаря дерева.
- Торговцы не производят товар; их роль — маржа при закупке у жителей
  (`MerchantBuyMargin`) и наценка при продаже еды (`SellPriceFactor`).
- Население не восстанавливается: рождаемости нет, умершие не заменяются.
- Все случайности — стартовые деньги — идут из одного `System.Random(seed)`;
  порядок обитателей фиксирован ⇒ полная детерминированность.

## Правила для агентов/разработчиков

1. Любое новое число (скорость, граница, порог) добавляй в `GameConfig`, а не в код.
2. В `WorldSim.Core` запрещены `Console.*`, ввод-вывод, графика, `DateTime.Now`,
   `Random` без seed.
3. Симуляция обязана оставаться детерминированной: никаких параллельных циклов
   по жителям и неупорядоченного LINQ-обхода словарей с недетерминированным порядком.
4. Перед коммитом: `dotnet build && dotnet test` — всё зелёное.
5. Тесты 10 000 тиков должны проходить за секунды — не добавляй тяжёлых операций в тик.
